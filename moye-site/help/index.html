Windows 版如何安装？

Windows 10/11 64 位用户可运行 Moye-18.3.2-Setup-Win64.exe。先保存并关闭旧版正在编辑的窗口，备份重要数据。安装完成后，使用新的“墨页”快捷方式启动。当前官网尚未提供公共安装包直链。

Android 能直接覆盖旧版安装吗？

Android 18.3.1 使用与此前同签名 safe-sync 发布系列一致的签名，在相同包名与签名条件下可覆盖安装。最初使用不同签名的旧版本不保证可直接覆盖。为了避免数据丢失，请先备份，不要贸然卸载原应用。

墨页支持离线阅读吗？

已保存并完整缓存到本机的书籍可在离线状态下阅读。外部在线来源未缓存的内容不在此保证范围内。建议在出行前检查所需章节是否已保存。

电脑和手机如何同步书库？

墨页保留同一局域网环境下的书库同步能力。两台设备需要能够互相连接；遇到连接问题，请检查是否连接同一网络及系统防火墙、局域网访问权限。同步前建议保留重要书库备份。

写作草稿会自动在双端合并吗？

不会。手机写作草稿与 PC 写作工作区目前没有新增跨端自动合并。写作资料可以通过导出备份或生成阅读副本后再进行适合的转移；请不要把书库同步当成实时协作编辑。

已经有公网账号、验证码和云端实时备份了吗？

现有发布记录尚未确认这些公网后端能力已正式部署，因此官网不将它们列为已上线功能。建议继续使用本地备份与现有局域网功能。

安装后书库数据不见了怎么办？

请不要连续卸载或重装，以免覆盖原有文件。先核对旧版与新版的书库目录和登录/本地空间，再检查是否存在此前导出的备份。若仍无法找回，建议保存当前现场并依据具体版本排查。

下载的文件如何核对完整性？

在 Windows 可使用 Get-FileHash 计算 SHA-256；在其他系统使用相应的校验工具。将结果与下载中心列出的完整校验值逐字符对照，不一致请不要运行安装程序。

重要提醒：更新或迁移前，先备份书库与写作文件。跨设备传输、不同签名 APK 覆盖安装，以及未缓存内容的离线打开，都可能受到设备和版本条件限制。
