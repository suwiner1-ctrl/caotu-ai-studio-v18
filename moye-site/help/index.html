下载安装

墨页支持哪些设备？
当前提供 Windows 10 / 11 的 64 位桌面端，以及 Android 手机端 APK。尚未发布正式的 macOS / iOS 安装包。
Windows 升级如何保留原有数据？
升级前先保存正在编辑的文字并关闭旧版窗口，再运行最新 Windows 安装包。现有安装程序采用独立版本目录，旨在保留原书库和写作文件；建议先备份自己的重要数据。
Android 可以直接覆盖更新吗？
18.3.1 的 APK 可覆盖此前同包名、同签名的安全同步版本。不同签名或不同包名的早期版本，不能保证直接覆盖安装。不要为升级贸然卸载旧应用，避免原有应用数据被删除。
为什么下载页暂时没有公开直链？
已有双端构建文件和 SHA-256 校验记录，但公开的安装包托管尚在配置中。为避免把无效或未验证的地址当作正式下载链接，页面暂时只提供文件版本和获取说明。

书库同步与备份

电脑与手机如何同步书库？
当前支持同一可互通局域网内的书库同步。请保持两台设备连接至可互访的网络，并使用应用内对应同步入口；如遇网络隔离、防火墙或不同网段阻断，可能无法连接。
能在外网自动同步吗？
目前尚未提供正式可用的公网账号、邮箱验证码和云备份服务。官网不会把这类开发计划宣传为已上线能力。
电脑写作草稿会同步到手机吗？
写作草稿与电脑写作工作区尚未实现跨端自动合并。可以根据实际需求使用阅读副本同步或导出备份功能，操作前请先保存草稿。

阅读与创作

怎样回到上次读到的位置？
墨页记录阅读位置与进度。重新打开书籍时，使用上次阅读位置或继续阅读入口，便可接着原来的章节浏览。
可以搜索章节或快速定位段落吗？
可使用章节目录与查找工具。18.3.0 起加入相邻段落定位功能，手机和电脑端分别从阅读页面相应工具入口访问。
桌面写作中心支持哪些内容？
Windows 版提供章节目录、草稿编辑和保存恢复能力，帮助集中组织创作内容。重要作品仍建议定期导出并额外备份。
